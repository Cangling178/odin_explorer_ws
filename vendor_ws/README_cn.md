# ODIN1 厂商底层工作空间

[English](README.md) | 简体中文

预留给来自厂商仓库的 `src/odin_ros_driver`。厂商源码、SDK 二进制和底层工作空间构建产物不纳入上层 Git 仓库。`COLCON_IGNORE` 防止根目录意外发现这些包。自研构建在根目录使用 `--base-paths src`，不是在此目录执行。

导入前：核对精确驱动/固件组合并审阅构建脚本。厂商文档对目录布局有要求，因此包直接放在本底层工作空间的 `src/` 下。在本目录按审阅后的厂商流程构建；自研基础工程不会调用它。

成功导入/构建后，记录提交 SHA、许可证、SDK 来源、固件、本地补丁和冒烟测试报告。先加载此底层工作空间，再加载自研叠加层。验收要求见 `docs/04_odin1_integration.md`。基础工程没有安装厂商驱动。
