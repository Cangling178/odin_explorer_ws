# 视觉循线观测接口

[English](README.md) | [简体中文](README_cn.md)
`LineObservation` 在同一消息中携带采集时间戳下的局部路径、图像健康状态、路径有效性与置信度、
角点、观测出口方向及出口数量。所有几何量使用 `path.header.frame_id`，时间戳是原图采集时间。
`image_valid` 只表示图像及投影健康，不表示一定看到了黑线。

正常跟踪不允许使用空路径行驶。只有带时间、累计移动距离和累计旋转上限的转角流程，才可以短暂
使用已保存在轮式里程计坐标系中的真实观测；期间仍必须持续收到健康图像、TF 和里程计。
多出口会被拒绝。消息不包含场景名称、参考路线、仿真真值或结束区域。

接口版本：0.1.0（独立场景原型）。
