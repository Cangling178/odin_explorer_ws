# 仓库与配置规范

[English](11_repository_guide.md) | 简体中文

## 文件归属

自研包源码放在 `src/odin_racer/`。实现后，每个包拥有自己的运行参数和启动资源。硬件事实放在 `hardware/`，赛道事实放在 `tracks/`，实验专属快照放在 `experiments/`。生成地图和大型采集文件放在不纳入 Git 的 `data/`。

厂商源码放在独立且不纳入主仓库的 `vendor_ws/src/` 底层工作空间。集成时固定提交并记录补丁，不把厂商 SDK 二进制复制进自研包，也不能丢失上游许可证声明。

## 模板与运行配置

`*.template.yaml` 是供人工审阅的规格表，含 `null` 和描述性字段，不能传给运行中的 ROS 节点。实现组件时，按真实节点参数结构创建经过验证、带版本的运行文件。明确记录从硬件/赛道资料到运行参数的转换，启动前检查必填字段。

避免重复维护调参常量。机器人变体选择几何参数和设备绑定，赛道版本选择路线几何，实验选择控制器参数方案。运行元数据中记录这三者。

## 数据规则

简要结果、文本配置和合成测试样例保存在 Git 中。不要提交录包、原始视频、点云、设备 SDK 二进制或凭据。外部采集文件应记录相对存储引用、内容哈希、大小、采集背景和保留说明。用户提供的赛道 JPEG 是初始本地仓库中唯一的小型参考图，加入仓库不会改变其所有权。

## 文档语言

保留英文原文，并以同目录下的 `<原文件名>_cn.md` 提供中文版。中英文页面互相链接；中文版中的文档链接优先指向对应中文版。命令、标识符和配置字段保持原样。修改技术含义时同步更新两个版本，避免要求或实现状态不一致。

## 变更完成标准

行为和接口已经记录、相关检查通过、需求有验证依据、状态准确，才算完成变更。包能构建不代表未来子系统已实现。用任务编号记录已知限制，不要将其隐藏在 TODO 值中。
