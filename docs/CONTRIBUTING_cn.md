# 本地协作规范

[English](CONTRIBUTING.md) | 简体中文

保留英文文档，并为 Markdown 文档提供同目录的 `_cn.md` 中文版。标识符、代码注释和 Git 提交说明使用英文。技术要求变化时同步更新两个语言版本。将修改关联到需求/任务，说明行为和验证依据。保持 `main` 可用，使用名称明确、范围聚焦的分支。

完成变更前运行结构检查、相关离线测试；修改包资源时运行 ROS 构建。实现解析器、几何、交叉点关联和停止条件时，添加行为回归测试，不要仅断言复制的占位值。

记录实测值时注明单位和来源。未测量的模板字段保持未填，并与运行参数分开。不能把工程骨架、合成数据或仿真结果称为实车性能。

即使没有远程仓库，也可用 PR 模板进行本地检查。外部依赖必须记录版本、许可证和集成依据。
