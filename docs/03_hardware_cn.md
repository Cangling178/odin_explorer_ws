# 硬件接入计划

[English](03_hardware.md) | 简体中文

## 已确认底盘和剩余测量

记录车轮布局、转向连接结构、负载下轮径、轴距、轮距、包含悬伸部分的车体轮廓、质量和大致重心。拍摄底部与接线照片，将测量值录入清单。驱动布局已确认，具体尺寸尚未测量。

项目负责人确认了两只后驱电机、两只前被动万向轮和 F4 下位机。采用两轮差速模型，每侧一只驱动轮。万向轮的回转和滚动仍会影响转向瞬态、滚动阻力及扫掠轮廓，不应把前轮建模为受驱动的滑移转向车轮。

建议车体原点位于后驱动轴中点。设轮半径为 `r`、有效后轮间距为 `b`、车体前进速度为 `v`、偏航角速度为 `omega`：

```text
left_wheel_radps  = (v - omega * b / 2) / r
right_wheel_radps = (v + omega * b / 2) / r
```

从实测半径和轮间距开始，验证每个车轮的比例修正系数。初步候选是每侧配置一个车轮关节的标准 ros2_control `diff_drive_controller`。Jetson 把车体目标转换成车轮目标；有反馈时由 F4 完成轮速闭环。运动学转换只放在一处，避免 F4 再次进行差速换算。

F4 按负责人提供的名称记录。STM32F4 只是暂定的系列理解，具体芯片和开发板型号尚未确认。选择构建工具链或外设之前，需要获取开发板标识、原理图、定时器引脚分配、烧录/调试器和现有固件。

## 电机与反馈清单

每只电机都应记录额定电压、数据手册中的堵转/电流额定值、减速比、带载速度和是否有编码器。区分电机每转脉冲数、正交计数以及车轮每转计数。核对左右电机通道及其与 F4/驱动器的接线。

如果没有编码器反馈，应记录限制，并在宣称精确轮速控制前确定反馈方案。上位机应向 F4 发送具有物理单位的目标轮速，不能把未标定 PWM 当作速度。

## 电源与接线交付物

完成电气框图，包含电池、保险丝、便于操作的电机停止装置、电机供电、Jetson 稳压供电、ODIN1 供电和通信。按**实际载板和模组**核对额定值，不能把某开发套件接口电压直接用于另一种载板。隔离电机噪声对计算供电的影响，并记录接地和线缆应力保护。

测量带载转弯时的电压跌落、驱动器温度、Jetson 热降频和 ODIN1 断连情况。将预期值与实测值写入功耗预算；根据实测峰值和数据手册选择 DC/DC 电流余量。

## 安装

使用刚性、可重复定位的传感器支架，确保前轮到达黑线之前就能观察相应地面区域。检查近场盲区、车体遮挡、曝光模糊、振动，以及向地面倾斜是否损失定位特征。传感器安装位姿是标定参数，不是随意填写的 URDF 偏移。

如果 ODIN1 的 RGB 视野无法支撑任务，应在确认规则后评估独立普通相机；方案不默认使用专用循迹传感器。

## 完成依据

- 填写后的 BOM 和机器人参数表，并解释未决字段。
- 低速直行和两个方向转弯的实测结果。
- 编码器方向/比例表，以及超时和停止测试记录。
- 传感器与计算平台共同运行时的热与供电试验。
