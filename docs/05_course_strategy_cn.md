## 选定的感知模式

项目负责人要求按允许提前建图、预录路线和摄像头识别黑线处理。以实测或示教得到的有序路线为参考，使用局部 RGB 黑线观测提供误差反馈，用车轮/ODIN1 运动信息提供背景。地面可见性仍需实测；起终点、方向、评分参考点和允许误差尚未确定。

不能假定仅靠定位就能充分贴合黑线。可以把它作为实测诊断基线，但不能自动替代局部视觉反馈。ODIN1 漂移、对齐和控制误差会累积，小型平面赛板能提供的定位特征也可能有限。

## 计划中的感知流程

采集 RGB → 检查数据时效 → 应用正确相机模型 → 选择地面区域 → 分离黑线与背景 → 排除阴影和印刷标注 → 提取候选中心线 → 投影为以米表示的地面点。

先采用可解释的传统图像处理，保存中间调试图像。只有记录到的失败情况确实需要时，才增加更复杂模型。

交叉点附近输出多个候选分支。置信度应反映可见长度、分割质量、重投影检查和歧义程度。空白图像必须输出无效状态，不能输出零横向误差。即使将车体状态预测到当前控制时刻，也应保留观测原始时间戳。

## 路线拓扑和交叉点关联

点云或无序的最近黑线像素集合不是路线。用有序分段、行驶方向、累计距离 `s`、交叉点入口/出口标识以及起终点门表示赛道。即使两个测量点有相同世界坐标，也应保留各自分段编号。

把每次关联限制在上一分段附近的进度窗口内，再检查航向连续性、合理行驶距离和允许的下一条边。交叉点不能只按全局最近欧氏距离选分支。保留迟滞机制，只有观察到预期出口才推进状态。圈数判定需要按顺序经过检查点，并穿过有方向的终点门；仅靠接近起点不足以判定。

回放测试应覆盖交叉点的两次通行、在交叉处暂停、临时丢线、位姿跳变和故意进入错误分支。比赛模式不能让最短路径规划器为到达目标而跳过规定环路。

## 紧弯与物理可行性

理想绘图尖角的航向不连续。角速度和加速度有界时，运动中的机器人不能以非零有限速度精确跟踪这种尖角。平滑路线前，先测量允许横向偏差和车体扫掠轮廓。

规则允许停车时，本后轮差速底盘可能采用原地转向；要检查转向过程中万向轮重新对齐以及前部悬伸的扫掠范围。不能为了提高圈速把规定环路平滑掉，或越出允许走廊切弯。

## 控制开发顺序

1. 完成轮速闭环，通过低速直行和转弯试验标定几何参数。
2. 使用低速纯追踪或可比基线控制器，跟踪简单实测线。
3. 添加航向/误差反馈、受限前视距离以及考虑路线进度的路径选择。
4. 低速验证交叉点和每个紧弯。
5. 添加基于曲率的速度规划以及实测制动限值。
6. MPC 等更复杂控制器必须与同一数据集、同一已验证基线比较。Nav2 Regulated Pure Pursuit 是参考候选，但须测试所装版本对自交路线的处理。

## 速度曲线：拟用公式

对非零曲率 `kappa`，候选限制包括：

```text
v_curve <= sqrt(a_lateral_max / abs(kappa))
v_yaw   <= omega_max / abs(kappa)
v_next^2 <= v_current^2 + 2 * a_accel * ds
v_current^2 <= v_next^2 + 2 * a_brake * ds
d_stop >= v * total_latency + v^2 / (2 * a_brake) + margin
```

分别使用加速和减速幅值，并沿路线做前向/后向约束传播。还要限制轮速、转向能力、车体轮廓、可用前视范围和观测置信度。接近零曲率时避免除零。这些公式是设计边界，不是已经标定的限值。

以 0.5 m/s 行驶时，100 ms 延迟意味着制动开始前已经前进 0.05 m。这个距离例子说明小赛场上相机时序的重要性，不是推荐车速。应在进入紧弯前降速，而不是出现较大误差后才降速。每次只提高一个速度参数，并重复试验。

## 精度预算

分别考虑赛道测量/真值误差、相机投影误差、传感器到车体的外参误差、时间戳误差、定位漂移和跟踪误差。不能把估计器自身一致性当成绝对赛道精度。既评测全程，也评测各分段，避免高速直道掩盖弯道表现差的问题。
