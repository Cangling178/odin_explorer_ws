# ADR-0002：有序赛道与局部视觉反馈

[English](0002_ordered_visual_tracking.md) | 简体中文

状态：已选定设计方向，2026-09-10；相机可见性和标定仍是验证关卡。项目负责人允许建图、预录路线和使用相机。

背景：小型自交标线赛道上的速度与精度问题不同于一般点到点导航。仅靠位姿跟踪会相对黑线漂移，最短路径可能跳过规定赛道段。

决定：优先采用相对黑线的局部相机反馈，结合车轮/ODIN1 运动背景和有序分段进度。明确表达交叉点拓扑。

影响：局部视觉、标定和路线关联是核心组件。项目负责人允许提前保存路线；编写赛道数据前确认交叉点通行顺序。Nav2 作为可选能力或经过细致适配的控制器后端，不能让目标点规划器重新定义比赛路线。

验证：提高速度之前，在重复低速运行中独立测量黑线误差，并验证交叉点顺序正确。
