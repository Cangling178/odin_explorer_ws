# ADR-0003：工作空间与依赖边界

[English](0003_workspace_boundaries.md) | 简体中文

状态：基础工程已采用，2026-09-10。

背景：硬件、感知、控制和实验需要共同演进，厂商代码又有独立的构建假设以及版本/固件耦合。

决定：将自研资源保存在同一 colcon/Git 工作空间。将 ODIN1 源码隔离到 `vendor_ws/src/odin_ros_driver`，不参与根目录包发现。包名按职责命名，实测事实保持单一来源。

影响：需要明确加载底层工作空间并记录版本。初期包可以安装文档/模板，但不能因此声称已有可用驱动。大文件不放入 Git，也不要求远程仓库。

验证：包发现和构建清晰；不跟踪厂商产物；所有文档和小型评测样例均可在本地检查。
