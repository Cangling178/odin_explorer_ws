# 实车联调

当前只有模型预览与厂商开发机点云初检记录；没有实车自主运动入口。

1. **人工移动建图**：核对驱动提交、实物固件与 USB；在实际安装高度采集墙面、桌椅和门口，绕行返回起点；验证地图保存、重定位、闭环与已知尺寸残差。记录点云、位姿、TF、版本和场景。厂商地图不能直接当导航栅格。
2. **底盘台架与遥控**：核对 F4、驱动器、编码器和接线；轮子离地验证方向与轮速闭环，验证错误包、重复/乱序、断连和重启停车。实测轮径、有效轮距、速度和制动，不沿用仿真修正。
3. **统一定位与时序**：测量车体到传感器外参；确认每条 TF 唯一发布，区分局部连续里程计与全局回环修正；记录延迟、数据年龄和重启行为。设备标定原件不代表安装标定。
4. **指定目标导航并建图**：选定地图后端、验证占据/空闲/未知语义、清空与回环一致性；检查实测车体轮廓、障碍物高度、近距离与后方盲区。先在已观测可通行区进行低速到点与绕障；输入失效停车，不自动恢复。
5. **自主探索**：限定实验室范围，验证目标可达性、超时和不可达处理、无可达前沿时结束并保存。报告目标成功率、人工干预、定位失效、地图覆盖与遮挡区，全部失败保留。

每阶段保存可运行提交、配置、复现步骤和结果摘要；原始录包放 `data/bags/`，地图放 `data/maps/`。实车数值门限在试验前由实测能力确定。
