# 启动、联调与操作计划

[English](09_bringup.md) | 简体中文

## 阶段 0：基础工程，目前可用

构建各包，运行离线检查并启动模型预览。当前模型包含 CAD 车板和 Odin1、已记录尺寸的车轮、
简化装配、估算惯性及碰撞体；用于实车规划或轮廓验收前仍需核对实测几何。
独立 Odin 传感器、整车落地接触和 ros2_control 运动场景均已有启动入口及验证记录，
见[仿真说明](../simulation/README_cn.md)。整车运动场景已有随车传感器输出，局部循线及选定路线的连续整圈已实现。
见[完整地图仿真](../simulation/COMPETITION_LAP_cn.md)。下述阶段 1–5 描述仍待完成的实车工作。

## 阶段 1：电气与电机台架，尚未实现

检查接线/额定值记录以及物理电机停止装置。将车轮支撑离地，检查每通道方向、实测反馈和速度限值。拔掉通信并重启上位机，下位机必须超时停止，并要求主动重新使能。记录实测停止行为。

## 阶段 2：ODIN1 与估计器台架，局部接入已开始

厂商驱动已在开发笔记本构建，用户已确认 RViz 点云显示，见[厂商记录](../vendor_ws/README_cn.md)。
目标 Jetson/实物固件组合、图像与 IMU 质量、车体适配和估计器仍待验收或实现。

先采集厂商数据，核对坐标方向、采集时间和复位行为。检查静态场景、已知平移和双向旋转。融合输入前，确认每条 TF 只有一个发布者，并验证相机投影。

## 阶段 3：地面低速试验，尚未实现

从直线和大半径转弯开始。比较编码器、ODIN1 和独立测量的运动结果；标定车轮比例以及适用时的有效轮距。确认所需前视范围内的黑线可见性。测试任何降级运行模式前，先验证无效数据会触发停车。

## 阶段 4：完整赛道精度，尚未实现

加载经过验证的有序路线；项目负责人允许提前准备路线。先分别测试交叉点和紧弯，再测试完整路线。验证检查点与终点含义，使用外部参考测量误差，达到约定精度关卡。

## 阶段 5：速度试验，尚未实现

引入有界的曲率速度限制和实测制动能力。进行重复成对试验，保留原始依据并报告失败运行。每次只改变一个设置。不能以走错路线或抄近路换取更快成绩。

## 故障排查

| 现象 | 优先检查 |
| --- | --- |
| 看不到机器人模型 | 是否加载叠加环境、模型话题、RViz 固定坐标系 |
| 位姿旋转方向错误 | 坐标约定、IMU 轴、编码器方向 |
| TF 重复或跳变 | 厂商/估计器竞争发布、闭环校正 |
| 直线跟踪振荡 | 时间戳延迟、前视距离、车轮响应、曝光 |
| 交叉点选错分支 | 分段/进度关联和出口迟滞 |
| 转弯切到黑线内侧 | 可行半径、前视距离、速度和车体轮廓 |
| 运动中传感器断连 | 电压跌落、线缆晃动、USB 和温度日志 |
| 内部误差很好但肉眼明显漂移 | 参考系错误、用自身估计评估自身或标定问题 |

将故障记录为可复现任务，附提交、参数和依据。在依赖组件实现前，工程有意不提供 `race.launch.py`。
