## 当前风险

主要未决项是相机地面视野与安装、紧弯车体扫掠、轮胎打滑／被动支撑响应、传感器和执行延迟、供电／USB 稳定性及评分规则。错分支或缺失数据不能被统计成更快的有效完赛。模型省略项见[仿真模型](../../simulation/MODEL_cn.md)。

近期实车目标：轮速反馈＋真实 ODIN 图像投影＋短直线闭环。在获得硬件数据前，可补整圈起点偏差、传感器／里程计扰动验证；0.10 m/s 当前只有一次通过记录，重复脚本尚未暴露速度／前视参数。
