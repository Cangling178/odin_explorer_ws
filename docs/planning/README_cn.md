## 里程碑

硬件和规则未完整明确之前，按验证关卡推进，不预设固定日期。目前仅 M0 已完成验收，M1–M8 均未完成。
机械建模、厂商驱动本机构建与点云初检、基础运动仿真已开展并有记录；这些局部进展不代表
实车台架或自主循线里程碑已通过。SIM-001 仍在进行，随车传感器已集成；当前重点为黑线场景、算法闭环与回放。

| 里程碑 | 交付物 | 完成依据 | 依赖 |
| --- | --- | --- | --- |
| M0 基础工程 | 英文工作空间、可构建资源、本地 Git 和离线指标 | 构建/检查报告 | 无 |
| M1 需求与清单 | 剩余规则、F4 型号、额定值和尺寸 | REQ/Q 表与完整硬件表 | M0 |
| M2 电机与传感器台架 | 反馈控制、看门狗、ODIN1 采集和标定 | 台架日志、实测时序和地面可见性 | M1 |
| M3 低速跟踪 | 简单黑线控制和有效评测流程 | 直线/圆弧独立误差测量 | M2 |
| M4 正确完整路线 | 有序路线、正确交叉点、可行紧弯 | 十次重复尝试及失败记录 | M3、已测量赛道 |
| M5 精度基线 | 可重复达到的误差限值 | 标定版本和验收报告 | M4 |
| M6 速度优化 | 有界速度曲线与公平控制器对比 | 保持精度同时降低有效时间 | M5 |
| M7 比赛版本 | 固定参数、可重复启动 | 完整彩排和带标签的依据 | M6 |

早期关键是确认现有底盘能否在允许走廊内通过赛道，以及 ODIN1 相机能否充分看清黑线。先解决这两点，再进行高级规划器或 GPU 工作。

## 风险

评级是初始工程判断，不是测量出的概率。

| 编号 | 风险 | 影响 | 触发条件/依据 | 缓解措施/下一步决策 |
| --- | --- | --- | --- | --- |
| R-01 | 现有底盘无法通过紧弯 | 高 | 转弯半径或扫掠轮廓超出走廊 | 选算法前先测量 |
| R-02 | ODIN1 地面视野不足 | 高 | 盲区、模糊或黑线像素过少 | 安装/投影试验；符合规则的相机替代方案 |
| R-03 | 位姿漂移超过黑线容差 | 高 | 独立误差大于内部误差 | 局部视觉反馈和标定预算 |
| R-04 | 交叉点选错分支 | 高 | 进度跳到几何上邻近的分段 | 有序路线、方向和交叉点回放测试 |
| R-05 | 轮胎打滑和万向轮对齐随速度、地面变化 | 高 | 多次试验转弯误差不同 | 有效几何标定和速度限制 |
| R-06 | 感知/计算延迟造成超调 | 高 | 观测过期或执行延迟 | 时间戳核查、性能分析和考虑制动的前视距离 |
| R-07 | 驱动/固件/平台不匹配 | 高 | 厂商构建或 USB 数据失败 | 独立底层工作空间和精确测试版本 |
| R-08 | 电机噪声导致欠压或断连 | 高 | 仅带载时发生故障 | 实测功耗预算和接线修订 |
| R-09 | 评分参考点或弯道扣分改变验收要求 | 高 | 剩余评分细则 | 感知/预录路线已获许可；记录剩余限制 |
| R-10 | 评测错误奖励数据缺失或抄近路 | 高 | 快速运行存在数据空洞或错误检查点 | 覆盖率、有序关联和失败报告 |
| R-11 | 过多投入通用导航 | 中 | 比赛里程碑停滞 | 优先黑线/交叉点/控制基线 |

获得具体依据后，为风险分配负责人并更新状态。只有测试或已明确的规则才能关闭风险，提出缓解方案本身不算解决。
