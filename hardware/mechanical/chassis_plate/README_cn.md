[English](README.md) | 简体中文

本目录保留用户提供的 SolidWorks 零件和 STEP 原件；用户确认第一张实物俯视照片左侧为车头，万向球在前，驱动轮在后。

- STEP SHA-256：`3034a4fd0d791a35212bf166a0775f7630fcfa31570a78389df7a697e52937d8`。
- 转换日期：2026-09-12；工具：Gmsh 4.15.2、trimesh 5.1.0。
- STEP 毫米转换为 STL 米，网格不需要额外缩放。
- 预览轴映射：`(x, y, z) = (-CAD_z, CAD_x, CAD_y)`，保持右手系。
- 网格原点：水平包围盒中心、最低面 Z=0；外包尺寸约 247.416 × 220 × 33.5 mm。
- 三角面数：113696；导出后检查闭合性和面朝向一致性。
- 模型位置：相对后轮轴中心 `xyz=0.103708 0 0.02875 m`，根据下述用户尺寸计算。

生成文件为 `src/odin_racer/racer_description/meshes/chassis_plate.stl`。
转换脚本为 `tools/convert_chassis_step.py`；从工作空间根目录执行：

```bash
python3 -m venv /tmp/odin-cad-tools
/tmp/odin-cad-tools/bin/pip install gmsh==4.15.2 trimesh==5.1.0
/tmp/odin-cad-tools/bin/python tools/convert_chassis_step.py \
  hardware/mechanical/chassis_plate/车板.STEP \
  src/odin_racer/racer_description/meshes/chassis_plate.stl
```

仅重新生成网格时需要这些工具。常规 ROS 构建直接使用已生成的 STL。
尚未加入质量、惯性、碰撞、电机或接触模型；车轮采用实测尺寸的简化圆柱，Odin 占位已移除。
