# 各部件仿真范围与实车差异

[English](COMPONENT_SIMULATION.md) | 简体中文

2026-09-16 更新：[C++ 单分支视觉循线](LINE_FOLLOWING_cn.md)已实现，含显式使能与锁存停车；完整地图连续循线现已通过仿真验证；实车验收仍待完成。

状态日期：2026-09-13。适用于当前 Gazebo Classic 11 / ROS 2 Humble 整车运动场景，
默认启用随车 Odin 传感器。本文件按部件说明已经模拟的行为、采用的近似和缺失的实车特性。
运行命令与验收数据见[仿真说明](README_cn.md)，缺口优先级见[模型不足清单](MODEL_GAPS_TEMP_cn.md)，
工程任务仍统一维护在[项目计划](../docs/planning/README_cn.md)。

当前实现的是简化车辆动力学、随车传感器输出和底盘速度控制。外观、碰撞、动力学与数据输出
属于不同层次：有 CAD 外观不代表有精确碰撞，有质量和惯性不代表有完整电机或电子系统模型。
尚无完整实车对照数据，因此可以明确模型省略了什么，但不能给出与实车相差多少百分比的结论。

## 1. 机械结构

| 部件 | 当前模拟内容 | 与实物的主要差异 |
| --- | --- | --- |
| 车板 | CAD 外观、安装位置、简化碰撞包络 | 未计入质量；碰撞用盒体近似，填充部分孔洞和空隙；没有板材变形 |
| 两个后驱动轮 | 直径 66.5 mm、宽 26 mm、名义轮距 257 mm；旋转关节、质量、惯性和地面摩擦 | 刚性圆柱轮胎，没有橡胶变形、胎面细节及实测校准的滚动阻力 |
| 两个前万向球 | 球体与壳体外形、组件质量和接地支撑 | 球体固定在车体上，以低摩擦滑动近似滚动；没有球体旋转、内部轴承或真实滚动阻力 |
| 电机支架 | 简化 L 形外观、碰撞、质量和估算惯性 | 部分尺寸是建模假设；没有连接间隙、松动和弹性 |
| 铜柱 | 六角外观、圆柱碰撞近似、安装位置 | 长度 42 mm 为推导值；未计入质量，省略螺纹和螺母等细节 |
| 输出轴与轮毂连接 | 输出轴随车轮旋转，保留简化外观和碰撞 | 刚性连接，没有轴承阻力、连接松动或传动间隙；轴质量不重复计入 |
| Odin 外壳与安装 | CAD 外观、碰撞包络、280 g 质量及估算惯性 | 安装高度和姿态包含假设；没有支架振动、安装弹性和散热行为；实际装配间隙尚未验收 |

依据：[整车 Xacro](../src/odin_racer/racer_description/urdf/robot.urdf.xacro)、
[电机装配](../src/odin_racer/racer_description/urdf/motor_assembly.xacro)、
[Odin 总成](../src/odin_racer/racer_description/urdf/odin1.xacro)。

## 2. 质量、惯性与刚体划分

| 已计入部件 | 质量小计 |
| --- | ---: |
| 两个电机总成 | 340 g |
| 两个电机支架 | 94 g |
| 两套轮胎与轮毂 | 92 g |
| 两套万向球组件 | 71 g |
| Odin1 | 280 g |
| 合计 | **877 g** |

这些质量采用已有参考值，未经整车称重验证。877 g 是已计入部件的小计，不是完整车重。
车板、铜柱、电池、Jetson、F4 和驱动板等质量按现有约定暂缓；额外紧固件忽略。
质心和惯性按均匀盒体或圆柱估算，未使用实测惯性，也没有单独模拟电机内部旋转惯量。

[接触场景生成器](../src/odin_racer/racer_description/racer_description/contact_world.py)
将固定部件合并为一个 0.785 kg 车体和两个各 0.046 kg 的车轮，共三个动态刚体，
保留 25 个碰撞体。合并包含惯性旋转和平行轴项，不重复计重，源 URDF 的零件级 TF 树保留。
部件间没有柔性或松动，自碰撞关闭；不能据此进行精密装配干涉或结构振动验收。

## 3. 电机、减速器与编码器

| 项目 | 当前实现 | 与实物的主要差异 |
| --- | --- | --- |
| 电机外形与质量 | 简化外形、碰撞，每个电机总成计入 170 g | 部分外形尺寸为假设，惯性按均匀包围盒估算 |
| 驱动力产生 | PI 回路比较目标与实际仿真轮速，向车轮关节施加力矩 | 没有电压、电流、反电动势、PWM、启动死区或温升模型 |
| 减速器 | 建模外壳，输出轴随轮子旋转 | 没有模拟 1:28 内部齿轮传动、效率损失、齿隙或内部旋转惯量 |
| 编码器 | 直接读取 Gazebo 关节位置和速度作为轮状态 | 没有 GMR 脉冲、计数量化、回绕、漏计或设备采样延迟；500 线到车轮每转计数的关系仍待确认 |
| 执行器限制 | 轮速度上限 ±12 rad/s、力矩上限 ±0.1 N·m | 属于仿真初值，不是已确认的电机额定或极限性能 |
| 停车 | 零速目标或指令超时后，经差速控制器与轮速回路减速 | 没有复现真实驱动板的刹车/滑行模式及断电行为 |

当前轮速回路 Kp=0.02、Ki=0.05、Kd=0，积分力矩限幅 ±0.03 N·m，并启用抗积分饱和。
车辆运动经过力矩、惯性和地面接触计算，而非直接修改车体位置；但加速、转弯与制动表现
尚未对照真实 MG513X 电机及驱动器，不能作为实车性能结论。
执行器参数见 [sim_actuation.yaml](../src/odin_racer/racer_description/config/sim_actuation.yaml)。

## 4. Odin1 传感器与内部功能

| 传感器或功能 | 当前模拟 | 与真实设备的主要差异 |
| --- | --- | --- |
| RGB 相机 | 设备标定 FishPoly 几何投影，1600×1296、10 Hz；自定义 fishpoly CameraInfo；水平/垂直视场约 128.85°/103.30° | 有限 cubemap 与重采样精度；无曝光响应、运动模糊或图像噪声；普通针孔消费者需适配 |
| 深度/点云 | 240×180 射线、120°×90°、0.2–30 m、10 Hz；检测碰撞体并输出 PointCloud2 | 射线求交近似 DTOF；没有反射率/光照影响、测距噪声、多径、confidence 或 offset_time，也未模拟条件相关的远距离探测能力 |
| IMU | 约 400 Hz，随车输出角速度和加速度，包含静止重力响应 | 理想无噪声、无偏置漂移或温漂；400 Hz 是仿真设置，尚未核对设备实际采样/发送频率 |
| 传感器外参 | 沿 Xacro 固定关节链计算；相机相对外参采用设备标定副本转换后的值 | 机壳到雷达为 CAD 镜头中心估计，车体安装尚未完成实测标定 |
| Odin 内部 SLAM | 未模拟 | 没有厂商融合位姿、cloud_slam、建图、重定位或地图保存功能 |

当前相机和点云约 10 Hz、IMU 约 400 Hz，均按仿真时间计。台架和整车共用
[odin_sensors.yaml](../src/odin_racer/racer_description/config/odin_sensors.yaml)，
由 [sensor_world.py](../src/odin_racer/racer_description/racer_description/sensor_world.py) 生成传感器。

[calib_device.yaml](../hardware/mechanical/odin1/calib_device.yaml) 现已用于图像的 FishPoly 投影与 CameraInfo；
相对外参仍使用原有转换值。实现与验收见 [FishPoly 相机](FISHPOLY_CAMERA_cn.md)。
点云配置的 `resolution_m: 0.001` 是射线量程分辨率设置，不代表真实设备有 1 mm 测距精度。

相机观察视觉几何，射线检测碰撞几何。测试红色方块有外观和碰撞，可被两者观察；蓝色地面标记
只有外观，相机能看到它，点云仍返回其下方地面。这也意味着简化碰撞包络会影响模拟点云形状。

## 5. 地面、电子系统与控制接口

| 部分 | 当前模拟 | 尚未体现的实际因素 |
| --- | --- | --- |
| 地面接触 | 重力、接触刚度/阻尼、摩擦、落地和滑动 | 默认平整地面；未使用实测不平度、材料变化或校准后的轮胎接触模型 |
| 比赛赛道 | 按参考图搭建 2.00×1.50 m 黑白赛板，含完整弯道与交叉点；摄像头可见黑线 | 图片估计线宽约 21 mm，未经实测标定；黑线只有外观，点云返回平地；无正式起终点、路线顺序或判罚 |
| 转向与打滑 | 由接触物理产生运动，采用有效轮距修正 1.10 | 修正仅适用于当前模型，不能作为实车轮距标定；真实打滑趋势未对照 |
| F4 | 仿真轮速 PI 回路近似其部分执行功能 | 未运行 F4 固件，没有定时器、通信解析、硬件故障或独立看门狗仿真 |
| Jetson | 开发电脑运行 ROS 节点 | 没有 Jetson 算力、调度、功耗或热降频模型；已有 C++ 单分支感知与跟踪，Jetson 性能未验收 |
| 通信与时间 | ROS 话题、仿真时间、0.25 s 指令超时 | 没有实车串口/CAN 延迟、丢包和设备时钟偏移；仿真暂停时超时计时也暂停 |
| 电池与驱动板 | 未建立电气模型 | 没有电池电压变化、压降、驱动器效率、限流或欠压行为 |
| 定位输出 | 差速控制器根据轮位置计算里程计 | 没有车轮与 ODIN1 融合定位；Gazebo 世界真值仅用于独立验证 |

接触摩擦初值：后轮 0.8、前球 0.02、其他部件 0.5、地面 1.0，均未经实测标定。
详见 [ground_contact.yaml](../src/odin_racer/racer_description/config/ground_contact.yaml)。
摩擦模型存在不等于已经正确复现实车打滑；也不能根据 `slip1/slip2=0` 推断轮胎绝不打滑。

车体指令上限为 ±0.2 m/s、±1 rad/s，加速度上限为 ±0.3 m/s²、±1.5 rad/s²，
控制频率 100 Hz、里程计发布频率 50 Hz。它们来自
[simulation_controllers.yaml](../src/odin_racer/racer_control/config/simulation_controllers.yaml)，
用于当前仿真验证，不是实车测得的能力上限。0.25 s 是指令超时阈值，不是物理停车时间。

## 6. 已验证的能力与结果适用范围

已通过稳定落地、基础直行/转向/圆弧、限幅与停车，以及随车图像、点云和 IMU 的基础几何和运动响应验证。
完整命令、阈值、历史指标和本地报告位置见[仿真使用与验证](README_cn.md)。

[比赛参考图场景](COMPETITION_COURSE_cn.md)已通过初始直段的俯视/车载图像投影和短距离前进检查，
已新增局部黑线识别和低速跟踪，选定完整地图的连续跟踪现已通过仿真验收。该场景启用俯视相机时，本次 IMU 实收约 333 Hz、图像/点云约 10 Hz；
配置中的 400 Hz 是目标频率，应以具体运行报告为准。

目前可以验证模型装配关系、基本运动接口、传感器坐标变换和已知目标观测，为后续算法接入提供基础。
尚不能据此认定实车圈速、制动距离、定位精度、复杂光照下的感知效果或完整赛道通过能力。
上次随车传感器验收的实时因子约 0.62，只反映当次开发电脑和渲染/订阅负载，不能代表 Jetson 性能。

后续修改部件或模型时，同步更新本文件相应条目；通过实车对照后再记录误差、数据来源和适用条件。
